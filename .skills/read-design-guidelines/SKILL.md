# Design Guidelines Reader Skill

Use this skill to implement the new light-themed portfolio layout.

## Core Directives

1. **Light Theme**:
   - Ensure background is white (`#ffffff` or `#f9fafb`) and text is charcoal (`#1f2937`).
   - Remove neon glowing lights and space-themed dark mode indicators.

2. **Split Header Layout**:
   - Left: Hamburger menu.
   - Right: Two-column grid with `images/sayantan_pic.png` and text matching:
     - Name: `Sayantan Ghosh` (bold, black)
     - Role: `Product Thinker & UX Strategist` (grey, smaller)

3. **Center-to-Bottom Transition**:
   - Landing view is middle-aligned (centered Welcome intro and input box).
   - Upon first submission, welcome message and bottom logos fade out, and the input box glides smoothly to the bottom.

4. **Input Box Styling**:
   - White background, light border, and soft drop shadows.
   - Icons: Download on bottom-left, Mic + Send on bottom-right.

5. **Partner Logos**:
   - Display RummyCircle first, followed by Google + Cisco, followed by National Geographic + Hurix Digital (text/styled logo).
